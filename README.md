# Расходы

Личное приложение для учёта трат на айфоне. Это PWA: открывается с домашнего экрана во весь экран
и работает без интернета.

**Все данные хранятся только на телефоне** (IndexedDB). Этот репозиторий и GitHub Pages раздают
только файлы приложения, о тратах они ничего не знают. В интернет приложение ходит только за курсами
ЦБ на cbr-xml-daily.ru, и в запросе есть только дата.

## Установка на айфон

1. Открыть адрес приложения в **Safari**.
2. «Поделиться» → «На экран Домой» → «Добавить».
3. Запустить с иконки. Бэкап: «Настройки → Сохранить бэкап» → «Сохранить в Файлы».

Если удалить иконку, траты пропадут вместе с ней. Восстановить их можно только из бэкапа.

## Что умеет

- Ввод траты в 2–3 касания, шаблоны частых трат и подсказки.
- QR-код кассового чека: сумма и дата подставляются сами.
- Импорт выписки CSV/XLSX (T-Банк узнаётся сам), категории подбираются и запоминаются.
- Бюджеты по категориям, отчёты по месяцам, траты в валюте по курсу ЦБ (курсы обновляются сами),
  итоги в любой валюте на выбор.
- Партнёр: двое видят траты друг друга («Я / Партнёр / Вместе»). Траты шифруются на телефоне
  (AES-GCM, ключ передаётся через QR), посредник в Yandex Cloud хранит только шифр.

## Посредник обмена с партнёром

Код в `sync-server/`: `core.ts` — логика без привязки к облаку, `yandex.ts` — Cloud Functions +
Object Storage, `local.ts` — локальный запуск для проверки (`npx vite-node sync-server/local.ts`).
Развёртывание — `tools/yc-deploy.sh` (нужен `yc init`). Адрес функции лежит в переменной репозитория
`SYNC_URL` и попадает в сборку через `VITE_SYNC_URL`.

## Разработка

```bash
npm install
npm run dev        # http://127.0.0.1:8680
npm test           # Vitest
npm run build      # dist/
```

Пуш в `main` запускает тесты, собирает приложение и выкладывает его на GitHub Pages
(`.github/workflows/pages.yml`). Спека — [SPEC.md](SPEC.md).

Проверочные скрипты лежат в `tools/`: генератор QR-картинок для сканера и
`npx vite-node tools/check-statement.ts файл.csv` — как приложение видит выписку.
