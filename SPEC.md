# Расходы — PWA для учёта трат на айфоне

Спека от 26.10.2026. Статус: **черновик, ждёт утверждения**.

## Цель

Личное приложение для учёта расходов. Иконка на домашнем экране, открывается во весь экран,
работает без интернета. **Все данные хранятся только на айфоне** (IndexedDB), сервера с
данными нет. GitHub Pages нужен только чтобы один раз скачать файлы приложения и потом
получать обновления.

Один пользователь, одно устройство, основная валюта — рубль.

## Что входит в первую версию

### Ввод расходов
1. **Ручной ввод в 2–3 тапа.** Кнопка «+» → своя цифровая клавиатура (без клавиатуры iOS,
   поддерживает `500+250`) → сетка категорий → сохранено. По умолчанию дата «сегодня»;
   дату, заметку и валюту можно поменять, но это необязательно.
2. **Шаблоны.** Кнопки «Кофе 250 ₽», «Метро 70 ₽» на главном экране — запись одним тапом
   и «Отменить» на 5 секунд. Шаблоны создаёшь сам, плюс подсказки из самых частых
   пар «сумма + категория».
3. **QR с чека.** Камера читает QR-код ФНС (`t=…&s=…&fn=…&i=…&fp=…&n=…`) → подставляются
   сумма и дата → выбираешь категорию. Если камера не открылась, можно сфотографировать
   чек и распознать QR с фото. Повторно отсканированный чек ловится по `fn+i+fp`.
   Возврат (`n=2`) записывается как минус.
4. **Импорт выписки.** CSV/XLSX из «Файлов». Готовый пресет для T-Банка; для остальных
   банков — один раз указать, где дата, сумма и описание (настройка запомнится).
   Кодировку (UTF-8 или Windows-1251) определяем сами. Перед сохранением экран
   предпросмотра: категория подобрана по правилам «описание содержит X → категория Y»,
   правила дообучаются на твоих исправлениях. Дубли отсеиваются: та же операция из
   повторного файла, плюс ручная трата с той же суммой ±1 день (её предлагаем склеить).

### Анализ
5. **Отчёты.** Пончик по категориям за месяц, столбики за 6–12 месяцев, сравнение
   с прошлым месяцем, переход в список трат категории.
6. **Бюджеты.** Месячный лимит на категорию, полоска остатка, жёлтая при 80%,
   красная при перерасходе. На главной — сколько осталось на месяц.
7. **Несколько валют.** Трату можно записать в любой валюте, в отчётах всё в рублях
   по курсу на дату траты. Курс подтягивается с ЦБ (cbr-xml-daily.ru), когда есть
   интернет, — в этот запрос не уходит никаких твоих данных. Без сети берётся последний
   сохранённый курс, его можно поправить руками.

### Служебное
8. **Категории.** Стартовый набор (Продукты, Кафе, Транспорт, Такси, Дом и ЖКХ,
   Связь и подписки, Здоровье, Одежда, Развлечения, Подарки, Другое). Можно
   переименовать, поменять эмодзи и цвет, отправить в архив.
9. **История.** Список по дням, поиск по заметке, фильтр по категории,
   редактирование и удаление.
10. **Бэкап.** Экспорт всех данных в JSON через «Поделиться» → «Сохранить в Файлы /
    iCloud Drive», восстановление из этого файла, экспорт трат в CSV. Если бэкапа
    не было больше 14 дней — плашка-напоминание.
11. **Обновления.** Когда выходит новая версия, показываем «Доступно обновление»,
    данные при обновлении сохраняются.

## Что НЕ входит (сознательно)

- Siri и Быстрые команды: приложение на домашнем экране хранит данные отдельно от
  Safari, поэтому команда записать в него не сможет.
- Синхронизация с другими устройствами и общий бюджет.
- PDF-выписки (если банк отдаёт только PDF — добавим отдельно).
- Доходы, счета и остатки на картах.
- Face ID / PIN-код на вход.

## Как устроено

| Слой | Решение |
|---|---|
| Сборка | Vite + TypeScript |
| UI | Preact, свои компоненты, светлая/тёмная тема по системе, вырезы экрана (safe-area) |
| Хранилище | IndexedDB через Dexie, версии схемы с миграциями; `navigator.storage.persist()` |
| Офлайн | Service Worker + манифест (vite-plugin-pwa), иконки и `apple-touch-icon` |
| Графики | Свой SVG, без тяжёлых библиотек |
| QR | `qr-scanner` (работает в Safari на iOS, где нет BarcodeDetector) |
| XLSX | SheetJS, загружается только при импорте |
| Тесты | Vitest для логики, браузер с размером экрана iPhone для сценариев |

Деньги хранятся целыми копейками, никаких дробных чисел.

**Модель данных:**
- `expenses` — id, сумма и валюта, сумма в рублях, курс, категория, дата, заметка,
  источник (`manual` / `template` / `qr` / `import`), внешний ключ для поиска дублей,
  когда создано/изменено
- `categories` — название, эмодзи, цвет, порядок, архив
- `budgets` — категория → месячный лимит в рублях
- `templates` — название, сумма, валюта, категория, порядок
- `rules` — подстрока описания → категория (для импорта)
- `importProfiles` — какие колонки в файле какого банка
- `rates` — курсы ЦБ по датам
- `settings` — дата последнего бэкапа и прочее

Код лежит в `~/rashody`.

## Этапы

| # | Что | После этапа можно |
|---|---|---|
| 1 | Каркас PWA, ручной ввод, история, категории, бэкап | уже вести траты |
| 2 | Шаблоны, бюджеты, отчёты | видеть, куда уходят деньги |
| 3 | Валюты и курсы ЦБ | записывать траты в поездках |
| 4 | QR с чека | сканировать чеки |
| 5 | Импорт выписок | загружать историю из банка |
| 6 | Выкладка на GitHub Pages, установка на айфон | пользоваться |

Собираю последовательно. Парсеры (QR, выписки, курсы) не зависят от интерфейса, поэтому
их можно отдать одному субагенту параллельно с этапами 1–2 — по этой спеке.

## Как проверяю перед сдачей

- **Юнит-тесты:** разбор QR (покупка, возврат, мусор), разбор выписок (CSV в обеих
  кодировках, XLSX, пресет T-Банка), поиск дублей, пересчёт валют, подсчёт бюджетов,
  бэкап JSON → восстановление без потерь.
- **Сценарии в браузере** с размером экрана iPhone: добавить трату в 3 тапа, шаблон
  и отмена, бюджет краснеет при перерасходе, импорт файла, приложение открывается
  без сети после первой загрузки, обновление версии не стирает данные.
- **Проверяешь ты на айфоне** (это я сделать не могу): установка на домашний экран,
  камера на настоящем чеке, импорт настоящей выписки из «Файлов», сохранение бэкапа
  в iCloud Drive.

## Что нужно от тебя

1. **Аккаунт GitHub.** Я поставлю `gh`, а войти в него (`gh auth login`) нужно тебе:
   вводить пароли за тебя я не могу. Для бесплатного GitHub Pages репозиторий должен
   быть публичным: код открыт, но твоих данных в нём нет.
2. **Выкладка** — только после твоего «да» на этапе 6.
3. **По одной выписке из каждого банка**, которым пользуешься (CSV/XLSX), чтобы
   настроить парсер под настоящие файлы. Они останутся у тебя на Маке, в репозиторий
   не попадут.

## Риски

- Если удалить иконку приложения, удалятся и данные. Защита — бэкап и напоминание о нём.
- iOS иногда заново спрашивает доступ к камере при каждом запуске приложения с
  домашнего экрана. Запасной вариант — распознать QR с фото.
- Формат выписок у банков меняется. Тогда помогает ручная настройка колонок,
  без новой версии приложения.

# Этап 7. Партнёр: видеть траты друг друга

Спека от 26.10.2026. Статус: **черновик, ждёт утверждения**.

## Цель

Двое (ты и партнёр) ведут траты каждый на своём айфоне. Каждый видит траты другого
и общую картину. Чужие траты только для просмотра, правит их владелец на своём телефоне.

## Как это работает

1. **Подключение.** Ты: «Настройки → Партнёр → Подключить» → вводишь своё имя → на экране
   QR-код. Партнёр в своём приложении: «Подключиться к партнёру» → сканирует QR из приложения
   (обычная камера не подойдёт: у приложения на домашнем экране своё хранилище, отдельное от Safari).
   Запасной путь — длинный код текстом, переслать в Telegram и вставить.
2. **Ключ.** В QR лежат номер пары и ключ шифрования. Ключ есть только на ваших двух телефонах.
3. **Обмен.** Каждый телефон кладёт к посреднику зашифрованный снимок *своих* трат и категорий
   и забирает снимок партнёра. Это происходит:
   - при открытии приложения;
   - раз в минуту, пока оно открыто;
   - через 3 секунды после каждой правки.

   Когда приложение закрыто, iOS ничего не запускает, поэтому траты партнёра появятся, когда откроешь приложение.
4. **Шифрование.** Снимок сжимается и шифруется на телефоне (AES-GCM 256 через WebCrypto).
   Посредник видит только шифр, размер, время и номера пары и устройства. Чтобы чужой не мог
   подложить мусор в вашу пару, запросы подписываются токеном, выведенным из ключа. Посредник
   хранит лишь отпечаток этого токена.
5. **Отключение.** «Отключить партнёра» стирает твою копию у посредника и траты партнёра
   на твоём телефоне. Подключиться заново — новый QR и новый ключ.

Партнёр видит **все** твои траты, включая прошлые (так решили).

## Что появится в приложении

- **Переключатель «Я / Партнёр / Вместе»** наверху главной, истории и отчётов (только когда
  партнёр подключён). Выбор запоминается.
  - На главной: итог месяца и «по категориям» для выбранного режима.
  - В истории: траты партнёра с его инициалом на значке.
  - В отчётах: все цифры, пончик и столбики для выбранного режима.
  - Нажатие на трату партнёра открывает её только для просмотра.
- **Категории.** Стартовые категории у вас общие и в режиме «Вместе» складываются.
  Свои категории партнёра показываются с его названием и эмодзи.
- **Только мои:** «+», шаблоны, бюджеты и подсказки работают с твоими тратами. Бюджеты
  в режиме «Вместе» не пересчитываются (общий бюджет не выбрали).
- **Настройки → Партнёр:**
  - твоё имя;
  - статус («Аня · обновлено 2 мин назад»);
  - «Обновить сейчас»;
  - «Отключить».
- **Бэкап** по-прежнему содержит только твои траты. Траты партнёра хранятся у него
  и подтянутся заново.

## Посредник в Yandex Cloud

Из России соединения с Cloudflare режутся после ~16 КБ, поэтому — Yandex Cloud.

| Часть | Что |
|---|---|
| Функция | Cloud Functions, Node.js 22, ~150 строк без зависимостей, публичный HTTPS-адрес |
| Хранилище | Object Storage, приватный бакет; объект на устройство: `pairs/<пара>/<устройство>` |
| Доступ | сервисный аккаунт функции с правом только на этот бакет, отдельный каталог `rashody` |
| Запросы | «простые» POST без лишних заголовков, поэтому браузеру не нужен предварительный CORS-запрос; ответ разрешает только `https://judaah.github.io` |
| Лимиты | снимок до 3 МБ (≈ 15 лет трат) |

**Стоимость.** Укладываемся в бесплатный лимит: функции — 1 млн вызовов в месяц, хранилище —
1 ГБ и тысячи операций. Двое при обновлении раз в минуту дают несколько тысяч операций в месяц.
Если когда-то выйдем за лимит, это копейки.

Код посредника лежит в репозитории (`sync-server/`) с тестами. Логика отделена от Yandex Cloud,
поэтому при необходимости переносится на любой сервер.

## Что нужно от тебя

1. **Аккаунт Yandex Cloud** с платёжным аккаунтом (карта; так устроен бесплатный тариф): console.yandex.cloud.
2. **Один вход в `yc`.** Я поставлю его официальным установщиком, а токен ты введёшь сам.
3. **Партнёр** ставит приложение по той же ссылке и сканирует твой QR.

## Как проверяю

- **Юнит-тесты.** Шифр туда-обратно; чужой ключ не расшифровывает; испорченный шифр отвергается;
  посредник без правильного токена не пишет и не читает; снимок → траты партнёра без потерь;
  итоги и отчёты в трёх режимах.
- **В браузере.** Два «телефона» (порты 8680 и 8681). Подключение по коду; трата на одном
  через минуту видна на другом; правка и удаление доезжают; отключение чистит обе стороны.
- **Вживую после развёртывания.** Те же шаги через настоящую функцию в Yandex Cloud.
- **На айфонах (это ты).** Подключение по QR между двумя телефонами.

## Риски

- Ключ лежит в QR. Кто сфотографирует QR, сможет читать ваши траты. Показывай его только
  партнёру; при подозрении — «Отключить» и подключиться заново (новый ключ).
- Пока приложение закрыто, обмена нет — это ограничение iOS для веб-приложений.
- Траты партнёра на твоём телефоне тоже исчезнут, если удалить иконку. Это не страшно:
  они подтянутся заново от партнёра.
